## Root cause (PROVEN by code inspection)

`tangent_lower()` (verify_coboundary_floor.py ~lines 345–410) assembles the Hessian
matrix M from **entrywise lower bounds** of w″:

    scalar = _down(weights[(i, j)] * s2)   # s2 = lower bound of w'' over the span, can be NEGATIVE

then certifies convexity via exact LDL on M (`_arb_ldl_positive`). But

    M ≻ 0  and  H = M + N with N ⪰ 0 entrywise   ⇏   H ≻ 0.

Explicit 2×2 counterexample: M = I, N = [[0,2],[2,0]] ⇒ H = [[1,2],[2,1]], eigenvalues
{3, −1}. The true Hessian H uses actual w″ ≥ s2 entrywise, i.e. H = M + N with N ≥ 0
entrywise, so the LDL certificate does NOT establish convexity of F_B on the box.
On a non-convex box the tangent plane at the midpoint is not a lower bound, so
`pruned_tangent` boxes may contain points below target. **226,637 of the 1.07M prunes
used this invalid certificate** on the record run alone.

The interval prunes (`box_lower`) and pressure prunes remain sound (all F_B terms are
non-negative: p_i > 0, a_ij > 0, w = (K/K0)² ≥ 0, mins over cell ranges).

## CORRECTION (2026-08-21 late, found by builder subagent + independently reconfirmed)

**The counterexample above was evaluated against the WRONG objective.** Three pair-sum
conventions coexisted in the tooling:
- S1: 15 pairs (i,j), 0≤i<j≤5 on cumsum-y — used by joint_maxmin_v2.py, the float surrogate,
